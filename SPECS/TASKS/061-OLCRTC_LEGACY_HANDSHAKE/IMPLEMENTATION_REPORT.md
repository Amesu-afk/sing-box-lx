# Проверка восстановления olcRTC, 2026-10-29

TarnVPN alpha.69 / versionCode 721 сохраняет handshake v1 и существующие QR-параметры.
Jitsi ждёт удалённый bridge до первого smux-пакета и повторяет начальный обмен один раз
при EOF/закрытом потоке. Реконнект во время начального обмена не запускает параллельную
переустановку клиентского smux. В Telemost повреждённый VP8-кадр отбрасывается,
а KCP восстанавливает данные без ожидания 256 RTP-пакетов.

Go tests изменённых пакетов и go vet прошли. Собраны API 23/API 21 AAR для четырёх
ABI, main/legacy release APK. Подпись v1/v2/v3 совпадает с alpha.68, все восемь
упакованных native-библиотек сверены с AAR после stripping.

На Windows запущено то же мобильное ядро: HTTPS через оба сервиса, повторная загрузка
после простоя, контрольный RTT и повторный вход Jitsi проверены. На VPS сохранены
комнаты, ключ и Xray-конфигурация; добавлены обратимые systemd drop-in настройки.
После установки APK alpha.69 пользователь подтвердил на физическом Android:
оба профиля подключаются и сайты открываются. Android 5, длительный прогон
и переключение сетей отдельно не проверялись.
Серверный код olcRTC не включён в client-only репозиторий sing-box-lx.
