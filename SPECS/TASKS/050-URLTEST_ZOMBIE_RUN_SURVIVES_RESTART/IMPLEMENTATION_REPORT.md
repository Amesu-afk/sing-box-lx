# Отчёт: владение и отмена XHTTP-соединений

## Добавка 21 октября 2026

В рамках общего анализа XHTTP подтверждены red/green проверки: отмена временного dial ctx обрывала уже установленные packet-up/stream-up upload; ошибка открытия stream-one не освобождала ожидающий protocol Write; фатальная асинхронная ошибка stream-up upload оставляла download ожидающим; response Close ожидал cleanup перед отменой своего ctx.

Теперь после успешной передачи соединения upload владеет отдельным cancel context с сохранёнными values. Close завершает upload, ошибка stream-one закрывает read half pipe и передаёт исходную ошибку Write; ошибка stream-up закрывает оба направления и возвращает lease; response Close отменяет ctx до ожидания underlying body. Дедлайны и cancellation до передачи соединения сохранены. Принимающий здоровый сосед на том же HTTP/2 сокете продолжает работу при timeout другого запроса.

Общий header-budget, late/rejected response cleanup, packet-up ack и physical warm-state ведутся в задаче 002. Исходники и зависимости upstream не менялись. Новые регрессии входят в 70 проходящих XHTTP-тестов, go vet проходит. Собраны оба AAR/две release APK alpha.68, 255 Android unit-тестов без ошибок, native payload/подписи/версии проверены. Race не выполнен из-за отсутствия gcc. Проверка установленной alpha.68 на устройстве остаётся открытой; прежний общий статус задачи не закрывается на основании локальной проверки.

## Добавка 12 ноября 2026 — реплей stream-one и прогрев замены

Поле alpha.88 показало, что правки помогают в основном режиму «Блокировать»: в Авто каждый свайп Shorts — это новый stream-one дайл, и попадание на stale-мембер стоило полный warm-бюджет без страховки.

Теперь первый stream-one дайл на мёртвом мембере переигрывается один раз: аплинк до первых заголовков (только handshake) буферизуется и повторяется целиком на свежем мембере; второй таймаут роняет дайл. Ротация не теряет и не дублирует байты, break побеждает ротацию. Заменённый мембер дополнительно греется фоновым GET без лизы слота, чтобы следующий живой дайл не платил холодный бюджет. Контракт освобождения pending Write обновлён: Write принят в реплей-буфер, смерть дайла видна на Read.

Red/green: 4 новых теста (`streamone_retry_test.go`, `pool_warmup_test.go`) + обновлённый `TestStreamOneHandshakeTimeoutUnblocksPendingWrite`; полный набор пакета зелёный, `go vet` чист. Параллельно в клиенте phone-resolve правило получило явный `timeout: 3s` (прематч-резолв синхронный, ошибка — reject). Проверка на ленте — в alpha.89.
