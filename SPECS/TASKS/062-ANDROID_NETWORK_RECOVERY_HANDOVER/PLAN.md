# PLAN: 062 — ANDROID_NETWORK_RECOVERY_HANDOVER

1. Добавить регрессии смены сети во время wake/reset, серии handover, ошибки reset и отмены.
2. Разделить накопление причины и запуск job в существующем Android scheduler. Повторный wake объединять с текущим сбросом; новый handover сохранять до его завершения.
3. Сохранить debounce/cooldown и проверку поколения отменённой job; проверить отмену перед вызовом recovery.
4. Сохранить повторные уведомления `DefaultNetworkMonitor`, пока native callback не даёт подтверждение принятия интерфейса; публиковать сетевую ссылку между потоками через `@Volatile`.
5. Проверить тесты обеих Android-вариантов, форматирование и собрать подписанные APK для проверки на устройстве.

Область: `clients/android` и документация этой задачи. Go-код и зависимости ядра не меняются; native AAR повторно используется с проверкой соответствия. Новых точек касания upstream Go нет.
