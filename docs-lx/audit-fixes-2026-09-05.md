# Исправления по аудиту — 5 сентября 2026

## Внесено в исходники

- CI и Makefile создают `tarn-version-metadata.json`, который ожидает обновлятор.
- Android не предлагает несовместимый ABI и не скачивает HTML страницы релиза вместо отсутствующего APK.
- APK проверяется до установки (в основной сборке — до остановки VPN): пакет, более новая версия, подпись установленного приложения, минимальная версия Android. Проверка повторяется для файла из кэша. При смене предлагаемого релиза ссылка на кэш сбрасывается.
- HTTP-ограничения перенесены из общего Go/libbox API в Android-клиент: текст 16 МиБ / 30 секунд, APK 256 МиБ / 10 минут; чтение также ограничено при отсутствии Content-Length. Ограничены редиректы, запрещён переход HTTPS → HTTP, учётные заголовки не пересылаются на другой origin. Временный невалидный APK удаляется.
- Подписки: добавления, переименования и удаления строк выполняются одной транзакцией Room. Файлы удалённых серверов очищаются после коммита. При ошибке до коммита откатываются переписанные конфиги, sidecar и список подписок. Ошибка чтения конфига больше не маскируется. Повторный импорт перепроверяет URL под блокировкой; запоздавший ответ не восстанавливает удалённую подписку.
- `subscriptions.json` исключён из backup/device transfer. Чтение использует восстановление AtomicFile; повреждённый JSON не подменяется пустым списком.
- Root debug ZIP получает владельца — UID приложения и права 0600 вместо world-readable.
- Таймаут XHTTP больше не закрывает сокет с недавним входящим трафиком. Молчащие сокеты по-прежнему очищаются; это эвристика, а не доказательство смерти соединения.
- Backup-файлы local.properties и локальные Gradle-логи исключены из Git; ключи не удалялись. GO_VERSION согласован с go.version (1.26.5); исправлен устаревший синтаксис namespace Termux.

## Проверки

- Go: тесты `transport/v2rayxhttp`, `experimental/libbox`, `protocol/group` прошли, в том числе с `with_xhttp`. В `common/urltest` тестов нет.
- Android: normal 96/96 и legacy 83/83 unit-тестов прошли; release lint обеих сборок без ошибок (218/205 предупреждений и по 5 hints). Новые тесты проверяют HTTP-лимиты, цикл редиректов, снятие Authorization при смене origin, таймаут, отбор APK и проверку подписи/версии.
- Тест настоящей Room-БД через SQL-trigger вызывает ошибку удаления после вставки и переименования, затем проверяет восстановление прежнего набора строк.
- Проверка XHTTP через net.Pipe подтверждает сохранение сокета с входящим трафиком. Это не проверка реального сервера, TLS/REALITY или пропускной способности.

## Что ещё не закрыто

- Нет долговечного журнала общей транзакции файлов и БД. Kill процесса/потеря питания между файловыми записями и коммитом Room отдельно не защищены; обычный откат при исключении не равен crash consistency.
- Нужны device-тесты Android 5/6+: HTTPS после перехода на системный HTTP-стек, root ZIP/SELinux, обновление поверх установленной подписанной версии, XHTTP под потерями и нагрузкой.
- Остался долг lint и предупреждение Detekt 1.23.8 о ReportingExtension.file перед Gradle 10. Они не скрывались baseline/suppressions и не считаются исправленными.
- Новые AAR/APK и релиз в рамках этого прохода не собирались и не публиковались. Проверки Android использовали уже имеющиеся AAR; изменения XHTTP проверялись Go-тестами отдельно.
- Рабочее дерево содержит исходные изменения пользователя; общий commit/очистка не выполнялись.
