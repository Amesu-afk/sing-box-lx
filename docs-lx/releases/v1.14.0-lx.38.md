## 🆕 What's new

### 🤖 Tailscale in the Android core

- Was: `with_tailscale` was in every desktop and router binary since lx.32, but stripped from the Android AAR — LxBox had no Tailscale UI and it is the heaviest dependency in the APK.
- Now: the AAR is built with upstream's mobile set unchanged: `with_tailscale` plus `ts_omit_logtail`, `ts_omit_ssh`, `ts_omit_drive`, `ts_omit_taildrop`, `ts_omit_webclient`, `ts_omit_doctor`, `ts_omit_capture`, `ts_omit_kube`, `ts_omit_aws`, `ts_omit_synology`, `ts_omit_bird`, which drop client features a VPN app never calls. A `tailscale` endpoint, the `tailscale` DNS transport and a `derp` service can now appear in an Android config.
- Cost: `libbox.aar` 116.77 → 119.35 MB (+2.58 MB, +2.2 %), arm64 `libbox.so` +1.96 MB. Build time is unchanged (11:58 with the tag vs 12:15 without on the same machine): the Tailscale code was already compiled through `tailssh` under `with_gvisor`, only the endpoint registration was missing.
- LxBox gates Tailscale nodes on core `1.14.0-lx.38` or newer; on an older core the node is skipped with a warning and the rest of the config still builds.
- Unchanged: desktop and router binaries and their tag set, configuration, wire format, the upstream base (sing-box `v1.14.0` + 33). (FEATURE 001, SPEC 004)

## 🆕 Что нового

### 🤖 Tailscale в ядре для Android

- Было: `with_tailscale` с lx.32 входил во все desktop- и router-бинарники, но из Android AAR вырезался — у LxBox не было UI под Tailscale, а это самая тяжёлая зависимость APK.
- Стало: AAR собирается с апстримным мобильным набором как есть: `with_tailscale` плюс `ts_omit_logtail`, `ts_omit_ssh`, `ts_omit_drive`, `ts_omit_taildrop`, `ts_omit_webclient`, `ts_omit_doctor`, `ts_omit_capture`, `ts_omit_kube`, `ts_omit_aws`, `ts_omit_synology`, `ts_omit_bird`, которые убирают клиентские функции, не нужные VPN-приложению. В Android-конфиге теперь допустимы endpoint `tailscale`, DNS-транспорт `tailscale` и сервис `derp`.
- Цена: `libbox.aar` 116,77 → 119,35 МБ (+2,58 МБ, +2,2 %), arm64 `libbox.so` +1,96 МБ. Время сборки не меняется (11:58 с тегом против 12:15 без на той же машине): код Tailscale и так компилировался через `tailssh` под `with_gvisor`, не хватало только регистрации endpoint'а.
- LxBox гейтит Tailscale-узлы по ядру `1.14.0-lx.38` и новее; на более старом ядре узел пропускается с предупреждением, остальной конфиг собирается.
- Не меняется: desktop- и router-бинарники и их набор тегов, конфигурация, провод, база апстрима (sing-box `v1.14.0` + 33). (FEATURE 001, SPEC 004)
